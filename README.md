# ROPEX Fishbone / 5xWhy

Et lille statisk webværktøj til ROPEX-arbejde med:

- Fiskebensdiagram
- 5xWhy-analyse
- Tiltag / opgaver
- Gem/åbn projekt som JSON
- Eksport til PDF
- Dansk, norsk og engelsk sprogvalg

## Sådan bruges værktøjet lokalt

1. Download eller klon projektet.
2. Åbn `index.html` i en browser.
3. Alle filer skal ligge i samme mappe:
   - `index.html`
   - `style.css`
   - `script.js`
   - `html2pdf.bundle.min.js`

## GitHub Pages

Projektet er en statisk HTML/CSS/JavaScript-side og kan derfor hostes via GitHub Pages.

Vælg typisk:

- Branch: `main`
- Folder: `/root`

## Filstruktur

```text
index.html
style.css
script.js
html2pdf.bundle.min.js
README.md
.nojekyll
```
